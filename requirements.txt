# Learned reranker.
#
# LightGBM provides LambdaMART (objective=lambdarank), which optimizes NDCG
# directly over query groups instead of classifying candidates independently.
# Measured, that is worth +0.09 nDCG@10 over the same-family sklearn GBDT — the
# largest single modelling gain in the project, so it earns the dependency.
#
# It is the one dependency pip can install correctly and still fail to import:
# it links a system OpenMP runtime. Linux wheels bundle it; macOS needs
#     brew install libomp
# eval/train_reranker.py degrades to the sklearn models with an actionable
# message rather than crashing, so nothing here is a hard blocker.
